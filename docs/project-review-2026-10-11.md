# 全面审查与迭代报告 · 2026-10-11

本轮审查覆盖配置/解析、运行时生命周期、订阅、调度/健康检查、HTTP/SOCKS5 会话入口、GeoIP、管理 API/UI、依赖和 Docker/CI。通过分模块审查、跨模块复核、缺陷复现与回归测试落实修改；保留既有行为中合理的兼容路径。

## 2. 新功能与使用变化

- 主入口命名会话：`http://wang.task01:1234@127.0.0.1:2323`，同 ID 绑定同上游，失败后按池策略切换；裸用户名继续普通调度。
- 会话页提供随机 ID、脱敏预览、HTTP/SOCKS5/curl 复制、绑定查询及单条/批量重置；TTL/LRU 防止无限增长。
- 固定的是上游节点，不保证上游服务商的公网出口永不变化。已建立的连接不迁移，不重放业务请求。仅在连接拨号失败/不可用时选择其他节点。
- 旧来源 IP 粘性端口保持兼容且独立。稳定节点身份、端口和命名会话能跨 core reload/订阅更新保持；进程重启会清空内存会话。
- 管理密码修改后立即重新登录；多数代理设置仍需重载，重载会中断现有连接。
- 订阅任一源失败/空内容会使整次刷新明确失败并保留原集合，而不是静默使用缩小的部分结果。关闭定时刷新仍支持手动刷新。
- `round-robin` 作为兼容输入归一为 `sequential`，UI 使用一致值；自定义订阅间隔不会被下拉选项改写。

## 3. 性能实测

下表是同机本地 fixture/微基准，**不是公网代理吞吐或端到端网络延迟结论**。

| 场景 | 原路径 | 新路径 | 范围 |
| --- | --- | --- | --- |
| 8192 节点命名会话成员查找 | 约 56.9 µs、65,561 B、1 alloc/op | 约 39 ns、0 B、0 alloc/op | 稳定身份索引 fast path；不含拨号/加密 |
| 饱和日志 ring 写入 512 B | 约 118 ns、1,877 B/op | 约 11.7 ns、0 B/op | 内存写路径；不含文件 IO |
| 超大日志写入 | 约 66,059 ns/op | 约 700 ns/op | 同一饱和写 fixture |
| 10,000 节点页面 DOM | 826,022 个节点 | 18,678 个节点，减少约 97.7% | 该合成 fixture 与当前筛选状态，首批 300 条 |
| 配置/诊断页面渲染 | 约 967/3,047 ms | 约 315/337 ms | 本地浏览器 fixture，非 SLA |
| 订阅配置快照 | 复制全部 Nodes，O(N) | 32/8192 节点均约 100 ns、656 B、2 alloc/op | 只复制订阅字段与路径，成本不随 Nodes 数量增长 |

日志 ring 不消除读取/JSON 编码开销；UI 首批展示限制 DOM，点击“显示更多”会累积展开，后端仍返回全量节点。服务端分页与真正有界渲染属于下一阶段。

浏览器压力 fixture 为每个节点生成 60 条 timeline 事件（实际后端上限为 20 条）；DOM 计数时配置页已收窄到一个搜索匹配，配置/诊断首屏均另行断言 300 行。因此 97.7% 仅说明该固定测试场景的变化，不代表所有真实节点数据与筛选状态。

## 5. 升级注意事项

1. 源码构建使用 Go 1.26.9 或更新版本，Docker builder 固定为 Go 1.26.9；完整协议/流量功能需使用生产标签。
2. 先备份配置目录；保留 `node_ports.json`，身份兼容迁移会保留既有稳定端口。YAML inline 手动端口优先于自身旧映射；与其他节点已有映射冲突现在报错，而非悄悄改旧节点端口。
3. 优先目录挂载。单文件 bind mount 或父目录不可写时走锁内 in-place fallback，它有正常操作同步/失败恢复，但**没有断电/崩溃原子替换保障**；外部不遵循锁协议的编辑器也不受进程间事务保护。
4. 配置目录可能增加私有 `*.lock` 文件；它们是同步 sidecar，不是配置内容，不要在运行期间删除。
5. 人工禁用节点不再被健康探测自动解封；到期或手动解除才恢复。健康检查目标返回失败 HTTP 状态时不会被标成健康。
6. 对管理界面设置非空密码；复制的节点/会话 URL 仍含真实代理凭据。`management.password` 为空继续保持无需登录的既有行为。

## 6. 下一阶段路线图（尚未实现）

### P1：可观测性与生产运维

- 独立 `/healthz`、`/readyz` 和可选 Prometheus 指标：区分进程存活、监听就绪、可用节点；避免把一次外部探测等同 readiness。
- 可下载脱敏诊断包：配置版本、端口映射、健康/订阅状态、错误摘要；明确删除 URI、密码、订阅 token。
- 订阅结果完全不变时跳过 reload；先保证节点身份/顺序、settings、缓存状态与回滚语义一致，再省掉连接中断。
- 长期 soak 与实际 Docker 目录/单文件挂载测试，覆盖定时刷新、MMDB 更新、弱网络和容器信号退出。

### P2：大规模体验与架构

- 服务端节点分页/过滤、增量日志和事件版本号，减少全量 JSON 与浏览器缓存成本。
- 拆分单文件前端、集中 API 状态机与测试；图表资源本地托管或版本/SRI 固定，改善离线体验。
- 统一 Clash/URL/VMess JSON transport 模型，补齐 `h2-opts`/`http-opts` 和 TLS/ALPN round-trip。当前 Clash H2 转换与 builder transport 名称仍有兼容缺项，不宣称无损支持所有格式。
- GeoIP 长期数据库更新后的 region membership 重建；明确“选定地区无可用节点”应失败还是回退全球，保留现有回退直到完成配置/兼容设计。
- 为 GeoIP HTTP router 增加 WebSocket Upgrade 支持；当前没有这一能力。
- 配置可信反向代理/TLS 终止语义，细化 Origin scheme 和 Secure Cookie 行为；当前按直接监听 TLS 状态处理。

后续功能应按独立、可回滚变更推进，先补合同测试再改变已有路由/刷新语义。
